1. Module Functional Architecture & Signal Contract
The Convolutional Processing Element (conv_pe.v) implements a 9-tap weight-stationary, sequential Multiply-Accumulate (MAC) architecture for 3×3 convolution kernels. It time-multiplexes a single signed Q7.8 multiplier across 9 clock cycles per receptive field, reducing hardware multiplier requirements by 88.89% compared to parallel spatial unrolling.

mac_en IN 1 bit Computation enable; advances tap counter; halts on stall Throughput: 1 valid output feature vector every 9 clock cycles
